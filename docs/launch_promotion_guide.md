## 3. Product Hunt Launch Copy

### Details & Metadata
- **Product Name**: Enclavetools
- **Tagline**: Curated directory of AI tools you run on your own hardware.
- **Topics**: Artificial Intelligence, Open Source, Developer Tools, Privacy, Self-Hosted
- **Short Description**: Find local and self-hosted AI tools. No API fees, no subscriptions, total privacy.
- **Recommended Attachments**: `docs/assets/enclavetools_ph_thumbnail.jpg` and `docs/assets/enclavetools_hero_banner.jpg`

### Maker Comment (First Comment on PH)
```text
Hey Product Hunt!

I built Enclavetools because running cloud AI APIs gets expensive fast. You hand over private code and data, pay per token, and risk sudden rate limits.

Meanwhile, local open-source tools exploded over the last year. Developers created incredible LLM runners, on-prem coding assistants, and local vector databases. Finding these tools scattered across thousands of GitHub repos felt painful.

Enclavetools fixes that.

It is a curated directory of tools you run on your own machine or private server.

What you get:
- Search by hardware specs (VRAM, Apple Silicon, CPU-only).
- Filter by license, maturity, and category.
- Instant client-side search with zero lag.
- Quick submissions with automatic GitHub metadata fetching.

I built this using Astro 6, Vue 3, and Cloudflare Pages. Every public page pre-renders at build time.

Try it out and tell me what you think. What local AI tools do you rely on every day?

Drop a comment below or send feedback on Telegram: https://t.me/your_telegram_username
```

## 4. Hacker News (Show HN) Copy

### Title
`Show HN: Enclavetools – Curated directory of local & self-hosted AI tools`

### Text Post Body
```text
Hi HN,

I built Enclavetools (https://enclavetools.com) to help developers find AI tools they can run on their own hardware without cloud API dependencies.

Tracking local AI software across GitHub repos is annoying. Filtering by VRAM requirements, license types (MIT vs AGPL), or specific use cases takes too much manual digging. I created Enclavetools to solve that exact problem.

The tech stack:
- Astro 6 pre-rendered static pages with Vue 3 components
- Cloudflare D1 for data storage
- Tailwind CSS 4

All public pages pre-render at build time. Client-side search and tag filtering run instantly in your browser without hitting a server on every keypress.

Take a look. I'd love your feedback on the UX, taxonomy, or missing tools.
```
